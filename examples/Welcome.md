# A simpler place to read.

Markdown, with a little room to breathe. Open a document and focus on what it says.

## Make yourself comfortable

Use the **Aa** button in the toolbar to switch between Native Reader and Book Reader. Choose a light or dark appearance, or let Zen Marky Reader follow your Mac.

> Zen Marky Reader is for reading. The only thing it writes is a task checkbox, when you click one.

## The familiar details

- Clear headings and **bold ideas**
- A little *emphasis* when you need it
- Links that open in your browser, like [CommonMark](https://commonmark.org)
- Tables, quotes, and code with their own space

| Action | Shortcut |
| --- | --- |
| Open a file | ⌘O |
| Reload a file | ⌘R |
| Larger text | ⌘= |
| Smaller text | ⌘− |
| Actual size | ⌘0 |
