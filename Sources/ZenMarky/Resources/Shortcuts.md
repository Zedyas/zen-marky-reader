# Keyboard Shortcuts

| Action | Shortcut |
| --- | --- |
| Open a file | ⌘O |
| New tab | ⌘T |
| New window | ⌘N |
| Close tab | ⌘W |
| Close window | ⇧⌘W |
| Reload the file | ⌘R |
| Print | ⌘P |
| Copy / select all | ⌘C / ⌘A |
| Find | ⌘F |
| Find next / previous | ⌘G / ⇧⌘G |
| Show outline | ⌥⌘O |
| Zoom in / out / actual size | ⌘= / ⌘− / ⌘0 |
| Previous / next tab | ⇧⌘[ / ⇧⌘], or ⌃⇧⇥ / ⌃⇥ |
| Go to tab 1–8, last tab | ⌘1–⌘8, ⌘9 |
| Always show the tab bar | ⇧⌘T |
| Cycle windows | ⌘` |
| Minimize | ⌘M |
| Hide / quit the app | ⌘H / ⌘Q |
| Keyboard shortcuts | ⌘/ |

## Mouse

| Action | How |
| --- | --- |
| Open a file | Drop it on any window |
| Open a linked file in a new tab | ⌘-click the link |
| Group a tab | Right-click the tab, then Add Tab to New Group |
| Collapse or expand a group | Click its chip |
| Rename, recolor, or close a group | Right-click its chip |
| Move a tab or a whole group | Drag the tab or the chip; drop it on another window's tab bar, or outside every window for a new window |
| Close a tab | Middle-click it |
| Check or uncheck a task | Click the box |
| Copy a code block | Hover over it, then click the copy button |
| Zoom | Pinch on the trackpad |

## Settings

| Setting | Where |
| --- | --- |
| Reader style: Native or Book | Aa button, or View > Reader Style |
| Appearance: System, Light, or Dark | Aa button, or View > Appearance |
| Open files in a new tab or window | File > Open Files In |
| Tab bar with a single tab | View > Always Show Tab Bar |
| Front matter (title, date, tags) | View > Show Front Matter |
